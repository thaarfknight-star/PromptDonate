# استودیو پرامپت دونیت — PromptDonate

**پرامپت بده، گیف دونیت تحویل بگیر.** 🎨➡️🎞️

برنامه‌ی دسکتاپ فارسی (راست‌چین) که با هوش مصنوعیِ روی خودِ سیستم، از یک
جمله‌ی انگلیسی تصویر می‌سازد و بعد با پردازش تصویر همان عکس را به یک گیف
شفاف هشدار دونیت تبدیل می‌کند — مناسب اورلی استریم در OBS / Streamlabs.

## مسیر کار

1. یک سبک آماده انتخاب کن (۸ سبک: انفجار سکه طلایی، باران اسکناس، نئون
   سایبرپانک، حماسه آتشین، کهکشان بنفش، شمش طلا، اژدهای طلایی، سفارشی)
   یا پرامپت انگلیسی خودت را بنویس.
2. «🎨 تولید تصویر» — مدل Stable Diffusion 1.5 روی کارت گرافیک خودت تصویر
   ۵۱۲×۵۱۲ می‌سازد (چند ده ثانیه).
3. نام دونیت‌کننده و مبلغ را بنویس، «▶ پخش» را بزن تا پیش‌نمایش انیمیشن را
   ببینی.
4. «💾 خروجی گیف شفاف» — گیف با پس‌زمینه‌ی کاملاً شفاف ذخیره می‌شود.

## انیمیشن (پردازش تصویر)

روی عکس ورودی این‌ها اعمال می‌شود: ماسک گردگوشه با قاب طلایی و هاله‌ی نور،
زوم پانچی ورودی، لرزش صفحه و فلش نور هنگام ظاهر شدن متن، گلیچ RGB-split،
ذرات سکه و اسکناس، پرتوهای نور چرخان، وینیت طلایی — و نام/مبلغ با فونت
**B Nazanin** که مثل ژله وسط صفحه می‌پرد و مبلغ شمارش معکوس بالا می‌رود.

## اجرای بار اول روی ویندوز

- کاربر **هیچ‌چیز نصب نمی‌کند**؛ همه‌ی وابستگی‌ها داخل پوشه‌ی برنامه است.
- بار اول که «تولید تصویر» را بزنی، مدل Stable Diffusion 1.5 (حدود ۴
  گیگابایت) **یک بار** با اینترنت دانلود و داخل پوشه‌ی `sd_models` کنار
  برنامه ذخیره می‌شود؛ دفعات بعد آفلاین کار می‌کند.
- اگر دانلود از سرور اصلی قطع بود، خود برنامه از آینه‌ی `hf-mirror.com`
  تلاش می‌کند؛ اگر باز هم نشد، یک بار با VPN دانلود کن (فقط بار اول).
- انتخاب خودکار سخت‌افزار: انویدیا (CUDA) ← DirectML (گرافیک‌های AMD/Intel
  مثل Radeon 760M) ← مک (MPS) ← پردازنده.

## ساخت فایل اجرایی ویندوز

```bash
pip install -r requirements.txt
pip install torch diffusers transformers accelerate safetensors huggingface_hub torch-directml
pip install pyinstaller
pyinstaller build.spec
```

خروجی: پوشه‌ی `dist/PromptDonate/` — فایل `PromptDonate.exe` را **همراه کل
پوشه** منتقل و اجرا کن. حجم باندل به‌خاطر torch حدود ۱ تا ۱٫۵ گیگابایت است؛
طبیعی است.

## تست headless

```bash
QT_QPA_PLATFORM=offscreen python smoke_test.py
```

تست بدون GPU و بدون دانلود مدل اجرا می‌شود (تصویر مصنوعی جایگزین خروجی
Stable Diffusion می‌شود). نمونه‌گیری واقعی مدل فقط روی سیستم مقصد با
کارت گرافیک قابل تست است.
